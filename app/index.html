Remove background

Uses the AI Cutout model below first (best edge quality, especially hair) — if that can't run (e.g. no internet the very first time), it automatically falls back to the AI edge detection / offline method further down instead, so this always works one way or another. If the photo already has no background (this app removed it earlier, or the file was already a transparent cutout), this step is skipped automatically.

✨ AI Cutout — runs in your browser

The model the button above tries first: a portrait-matting model (not the real-time video-call one further down) — better at soft/blurred edges and hair. Downloads once (~7MB, needs internet that first time only, then cached), then every photo after that is processed entirely on your own machine: no server, no API key, no rate limit, nothing that can run out of credits or go down. Slower per photo than the fallback method (several seconds). Use this button instead of the one above if you specifically want this model with no fallback — useful for confirming it ran, or retrying it after a network hiccup.

Fallback method (used automatically if AI Cutout can't run)

Sensitivity22

This real-time (video-call-oriented) AI model, or the offline colour-based method if you turn it off, only runs when AI Cutout above is unavailable — or if you use the "remove background" text command, which also goes through this same fallback chain.

☁ Cloud AI removal (optional)

Sends the photo to a hosted neural background-removal service — remove.bg and Clipdrop need your own API key, ClearBackdrop needs none (free tier, rate-limited per IP instead). All three tend to give noticeably cleaner hair/edge detail than the built-in method above, since they're full trained models rather than classical edge detection. Any key you paste is used only for that request, kept only in this browser tab, and never saved anywhere by this app.

This needs a real outgoing network request, so it only works when this page is opened as its own browser tab. If you're viewing it inside another site's embedded preview/sandbox, that request usually can't get out — the built-in offline Remove Background above needs no network at all and always works, including in a sandboxed preview.

⚠ Because this is a static, client-side page, the key you paste below is visible to anyone who opens the browser's network/dev tools while using it. Fine for your own private use; if you publish this page for the public, don't leave a real key pasted in by default — have each user paste their own, or proxy the request through your own backend instead.

⚠ ClearBackdrop needs no key, which also means no account or contract is backing it — it's a third-party site, not remove.bg/Clipdrop-level established. Your photo leaves your browser and goes to their server to be processed; don't use it for anything you wouldn't want passing through an unfamiliar site, and worth a quick look at their privacy policy first if these are ID/passport photos.

Remove an object

Select the ◌ tool, paint over the unwanted object or blemish, then remove. Works best on small/medium objects over fairly simple backgrounds. Use [ and ] on your keyboard to shrink/grow the brush.

Brush size28

Spot Heal clones in real texture from nearby (colour-matched) — best for blemishes, pores, small marks, where a flat fill looks wrong. Remove uses a soft blended fill — better for bigger objects with no clean texture nearby to clone from.

Quick retouch presets

These just switch to this brush and size it for the job — paint over the spot, then click Spot Heal above (or Remove for the patch preset on bigger areas). Same engines as above, sized differently per job.

✨ Magic Remove

Select the ✨ tool, then click directly on an object once — it selects and erases it in one step, no brushing needed. Best on objects that sit on a fairly even/simple area. If it removes too much (or too little), adjust the tolerance and click again.
